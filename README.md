# Runlit — Marketing Website

Intro site for Runlit by Fidespark. Helps potential clients book a discovery call.

## Stack

Plain HTML / CSS / JS — no build tools, no dependencies.

```
index.html        all content and page structure
css/styles.css    all styles (mobile-first)
js/main.js        scroll reveal + mobile nav
```

## Preview locally

Open `index.html` in any browser. No server needed.

## Deploy

Connect this repo to [Netlify](https://netlify.com) or [Vercel](https://vercel.com) — they'll auto-deploy on every push to `main`.

## Update content

All copy lives in `index.html`. Search for the section you want to change and edit the text directly.

To swap the Calendly link, find and replace `https://calendly.com/grace-ge/30min` across `index.html`.
